# ArabicIDE v0.2.2

بيئة تطوير لـAndroid بواجهة عربية (RTL) ومساحة كود LTR. محرر Monaco يعمل محلياً دون إنترنت، وتشغيل الأوامر عبر Termux.

## تقرير الأخطاء للمطور

- التطبيق يسجّل تلقائياً أي تعطل (crash) وأخطاء المحرر والطرفية والحفظ في سجل داخل التطبيق.
- لعرض التقرير: القائمة ⋮ ← **تقرير الأخطاء**. ويظهر تلقائياً عند فتح التطبيق بعد تعطل سابق.
- زر **مشاركة التقرير** يرسله كملف نصي عبر أي تطبيق (واتساب، بريد، إلخ). زر **نسخ** ينسخ النص.
- التقرير يحتوي معلومات الجهاز والإصدار والتعطلات وسجل المحرر، ولا يحتوي محتوى ملفاتك.

## الجديد في v0.2.1

- **إصلاح اختفاء الكود وعدم ظهور الكيبورد:** الصفحة لا تُحمَّل الآن إلا بعد أن يصبح للمحرر حجم فعلي، والتخطيط يُحسب صراحةً ويُعاد عند أي تغيّر في الحجم.
- **زر لوحة المفاتيح** (أسفل يسار المحرر) لإظهار الكيبورد وتركيز المحرر.
- **دليل ربط Termux داخل التطبيق** مع أزرار نسخ الأوامر: من القائمة ⋮ ← «ربط Termux وأوامر التثبيت»، أو من أيقونة ⓘ في الطرفية، أو بالضغط على كلمة Termux في شريط الحالة. يظهر تلقائياً أول مرة إن لم يكن الربط جاهزاً.

## التشغيل

1. افتح المجلد في Android Studio (**File > Open**) وانتظر Gradle Sync.
2. شغّل التطبيق على هاتف Android 7.0 أو أحدث.

## ربط Termux (مرة واحدة)

1. ثبّت Termux من **F-Droid** (لا من Google Play) وافتحه مرة واحدة.
2. انسخ هذه الأوامر والصقها داخل Termux (زر «نسخ أوامر التفعيل» في الدليل):

```
mkdir -p ~/.termux
grep -qxF 'allow-external-apps = true' ~/.termux/termux.properties 2>/dev/null || echo 'allow-external-apps = true' >> ~/.termux/termux.properties
termux-reload-settings
```

3. أغلق Termux بالكامل (من الإشعار: Exit) ثم افتحه من جديد.
4. في ArabicIDE افتح الدليل واضغط **منح الصلاحية** ثم **اختبار الاتصال**. تظهر كلمة `ArabicIDE-OK` في الطرفية إن نجح الربط.
   إن لم تظهر نافذة الإذن، فأعد تثبيت ArabicIDE بعد تثبيت Termux.

## تثبيت الأدوات داخل Termux

الصق الأمر المناسب في Termux (كلها لها أزرار نسخ في الدليل):

```
pkg update -y
pkg install -y python nodejs
```

| اللغة | الأمر |
|---|---|
| Python | `pkg install -y python` |
| Node.js | `pkg install -y nodejs` |
| C / C++ | `pkg install -y clang` |
| Java | `pkg install -y openjdk-17` |
| PHP | `pkg install -y php` |
| Ruby | `pkg install -y ruby` |
| Go | `pkg install -y golang` |

## كيف تعمل الملفات

- ملفاتك داخل مساحة التطبيق الخاصة، وعند التشغيل تُنسخ الملفات النصية الصغيرة إلى `~/ArabicIDE/<اسم المشروع>` داخل Termux ثم يُنفَّذ الأمر هناك.
- إن زاد حجم المشروع عن نحو 65 كيلوبايت يُرسل الملف النشط فقط.
- الاستيراد والتصدير عبر مدير الملفات (SAF) يأتي في مرحلة لاحقة.

## إذا ظهرت مشكلة

- **المحرر البديل (نصي) بدل Monaco، أو شاشة فارغة:** الإعدادات ← سجل المحرر ← نسخ، وأرسله. السجل يتضمن أبعاد المحرر (`layout WxH`).
- **«لم تصل نتيجة»:** كرر إغلاق Termux بالكامل وتأكد من الأوامر أعلاه.
- **رمز الخروج 127:** الأداة غير مثبتة، وتقترح الطرفية الأمر المناسب.
- **فشل البناء:** أرسل نص الخطأ كاملاً.

## ملاحظة الصدق

لم يُبنَ المشروع ولم يُشغَّل على جهاز من جهتي. اختبرت صفحة المحرر وحدها في Chromium (تحميل، كتابة، إدراج رموز، تكبير الحجم بعد التحميل) وكلها نجحت، لكن لم أختبر الـWebView على الهاتف ولا ربط Termux. أول بناء عندك هو الاختبار الفعلي.
