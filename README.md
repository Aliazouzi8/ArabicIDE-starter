# ArabicIDE v0.2.0 — واجهة جديدة

بيئة تطوير لـAndroid بواجهة عربية (RTL) ومساحة كود LTR. محرر Monaco يعمل محلياً دون إنترنت، وتشغيل الأوامر عبر Termux.

## ما الجديد في هذه النسخة

- **مساحة عمل واحدة** بدل شاشات منفصلة: شريط علوي، علامات تبويب، المحرر، لوحة طرفية سفلية، وشريط حالة.
- **مستكشف ملفات** في درج جانبي (من اليمين): إنشاء وإعادة تسمية وحذف الملفات والمجلدات، وعدة مشاريع.
- **زر التشغيل ▶** يحفظ الملف ويرسل مشروعك إلى Termux ثم ينفذ الملف حسب امتداده (py, js, sh, rb, php, lua, pl, go, java, c, cpp).
- **طرفية** بسجل ناتج (stdout/stderr/رمز الخروج) وحقل أمر وأوامر سريعة.
- **شريط رموز** فوق لوحة المفاتيح: Tab، تراجع/إعادة، الأسهم، والأقواس والرموز الشائعة.
- **حفظ تلقائي**، واستعادة التبويبات المفتوحة عند فتح التطبيق، وإعدادات (حجم الخط، التفاف الأسطر).
- إصلاح تداخل الواجهة مع شريط الحالة ولوحة المفاتيح (Edge-to-Edge).
- Monaco داخل المشروع (`assets/editor/vs`)، ولا حاجة لأي تنزيل.

## التشغيل

1. فك ضغط المشروع وافتحه في Android Studio (**File > Open**).
2. انتظر Gradle Sync ثم اضغط **Run ▶** على هاتف بنظام Android 7.0 أو أحدث.

## إعداد Termux (مرة واحدة)

1. ثبّت Termux من **F-Droid**، وافتحه مرة واحدة.
2. داخل Termux نفّذ:

```
mkdir -p ~/.termux
echo "allow-external-apps = true" >> ~/.termux/termux.properties
termux-reload-settings
pkg install python
```

3. في ArabicIDE افتح الطرفية (زر الطرفية في الأعلى) واضغط **منح الصلاحية**.
   إن لم تظهر نافذة الإذن، فأعد تثبيت ArabicIDE بعد تثبيت Termux.

## كيف تعمل الملفات

- ملفاتك تُحفظ داخل مساحة التطبيق الخاصة، ولا تظهر لتطبيقات أخرى. الاستيراد والتصدير عبر مدير الملفات (SAF) يأتي في مرحلة لاحقة.
- عند التشغيل تُنسخ ملفات المشروع النصية الصغيرة إلى `~/ArabicIDE/<اسم المشروع>` داخل Termux، ثم يُنفَّذ الأمر من هناك.
- إن زاد حجم المشروع عن نحو 65 كيلوبايت يُرسل الملف النشط فقط.

## إذا ظهرت مشكلة

- **المحرر البديل (نصي) ظهر بدل Monaco:** افتح الإعدادات ثم **سجل المحرر** وانسخ ما فيه.
- **"لم تصل نتيجة":** تحقق من `allow-external-apps = true` وأن Termux شُغّل مرة واحدة.
- **رمز الخروج 127:** الأداة غير مثبتة، وستظهر لك رسالة بأمر `pkg install` المناسب.
- **فشل البناء:** أرسل نص الخطأ كاملاً.

## ملاحظة الصدق

هذه النسخة كُتبت دون القدرة على بنائها أو تشغيلها في بيئتي. فحصت توازن الأقواس وصياغة JavaScript، لكن لم يُجرَّب البناء ولا الواجهة ولا Termux على جهاز. أول بناء عندك هو الاختبار الفعلي، وأي خطأ يظهر أصلحه.
